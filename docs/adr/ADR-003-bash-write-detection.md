# ADR-003 Bash 写入判定：事前解析加事后比对

- Status: Proposed
- Relates: FR-012, FR-025, MOD-11

## 背景

代理可以用任意命令写文件（重定向、`sed -i`、`python -c`、构建脚本）。只做事前解析会漏掉解释器和脚本；只做事后比对拦不住仓库外的写入和危险命令。

## 决策

- 事前：用 `mvdan.cc/sh/v3/syntax` 解析命令，识别重定向和已知写命令的目标路径，按门禁规则拒绝。
- 事后：放行的命令执行前记录仓库文件状态，执行后比对，范围外的改动恢复为执行前内容，新建文件删除，并反馈给代理。
- 引入第三方依赖 `mvdan.cc/sh/v3`（BSD-3-Clause），这是 ADR-001 唯一的例外。

## 后果

- 覆盖任意写法；事后恢复只作用于仓库内文件。
- 事前快照需要遍历仓库文件元数据，大仓库的耗时由 NFR-003 基准测试约束；大于 1 MiB 的文件只记录元数据，被改动时报告但不恢复。
- 依赖登记在依赖白名单（FR-026 于 Release 2 生效时补录）。
