# ADR-007 规则只读一次性加载的项目快照

- Status: Proposed
- Relates: NFR-003, FR-028, MOD-09, MOD-04

## 背景

规则需要产物、锁文件、git、测试报告、源码等多种输入。若各规则自行读取，难以控制性能，也难以用样本测试规则。

## 决策

MOD-09 一次性加载只读快照，规则只接收快照。门禁路径使用轻量快照（不读测试报告和源码）。规则样本即构造好的快照。

## 后果

- 规则是纯函数，样本测试简单，结果确定（NFR-001）。
- 快照加载成为性能热点，NFR-003 的基准测试以它为主要对象。
- 编排层通过快照间接使用叶子模块，app 扇出保持在 7 以内。
