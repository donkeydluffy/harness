# ADR-011 外部工具只在专用命令中运行，全量检查读报告

- Status: Proposed
- Relates: FR-014, FR-021, FR-055, MOD-02, MOD-08, MOD-16, FLOW-11

## 背景

lint、按接口的覆盖率、冒烟测试都要运行外部程序，耗时长，结果还依赖本机环境。全量检查会在任务完成和每次会话结束时运行，必须快，而且结果确定。

## 决策

- `harness check lint`、`harness check unit` 运行工具，并把结果连同源码哈希写入 `.harness/reports/`；全量检查只读报告：报告缺失、过期或有问题时失败。测试报告沿用同样做法。
- 冒烟测试不写报告、不计入全量检查，只在 `harness check smoke` 与 CI 中运行。
- 被否决的方案：在全量检查中直接运行工具。会话结束检查会因此变慢，工具没装时还会挡住与源码无关的检查。

## 后果

- 代理改完源码要先运行 `harness check lint` 和 `harness check unit`，否则报告过期；失败信息会提示运行哪个命令。
- 报告不提交到仓库，CI 中重新生成。
- app 新增对 MOD-14、MOD-15、MOD-16、MOD-17 的依赖：编排外部工具报告、接口快照、批准与自定义规则。
